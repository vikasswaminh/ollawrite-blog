1.1 STRICT ZERO HOVER HIGHLIGHT ON ARTICLE CONTENT ELEMENTS
------------------------------------------------------------
- Requirement: Inside the blog post page of every single article, placing or hovering
  the cursor over the TL;DR summary box, Key Takeaways container/cards, and complete
  content comparison tables must NOT highlight anything (zero visual shifts).
- Root Cause Identified: Previous CSS rules contained broad `p:hover` and `h*:hover`
  selectors that tinted all body text, headings, and table cells red on hover, and
  tabindex attributes applied to content cards triggered focus outlines.
- Solution Implemented:
  * Removed the dynamic tabindex/focus assignment useEffect in BlogPostPage.tsx.
  * Added strict CSS overrides in `src/styles/knowledge.css` for `.tldr-box`,
    `.key-takeaways-box`, `.key-takeaway-card`, `.main-content-card`, and `table.prose-table`.
  * Enforced across all states (:hover, :focus, :active):
    - transform: none !important; (eliminated 3px translateX shift animations)
    - cursor: default !important;
    - Neutral borders and backgrounds locked to static slate/ice-blue palettes.
    - Heading and paragraph text colors locked to high-contrast static colors.

1.2 REMOVAL OF UNINTENDED INNER BORDER LINES INSIDE TL;DR BOX
-------------------------------------------------------------
- Issue Identified: A previous wildcard rule (`.tldr-box *`) applied `border-top: 6px solid #003db3`
  to all inner children, creating two unwanted blue lines:
  * Line 1: A short horizontal blue bar directly above "TL;DR Summary" (on the inline-block <h3>).
  * Line 2: A full-width horizontal blue bar directly below "TL;DR Summary" (on the block <p>).
- Fix Applied:
  * Replaced wildcard border assignments with explicit `border: none !important;`
    (and `border-top: none !important; border-bottom: none !important; outline: none !important;`)
    on all child elements inside `.tldr-box` (`<h3>`, `<p>`, `<span>`, etc.).
  * Both inner lines were completely removed while preserving the outer container's clean border.
